## Available Tools
- open_app: Launch an application. args: {"name": "app name"}
- quit_app: Quit an application. args: {"name": "app name"}
- set_volume: Set system volume 0-100. args: {"level": number}
- battery: Read battery status. No args needed.
- list_apps: List running apps. No args needed.
- open_kitty: Open a new kitty terminal window. No args needed. Use this when Nik says "new terminal", "new kitty", or "open terminal window".
- audio_device: Switch microphone or speaker device. args: {"device": "EXACT device name", "type": "input or output"}. IMPORTANT: device names must match exactly. Common devices on Nik's Mac: "MacBook Pro Speakers" (output), "MacBook Pro Microphone" (input), "EarPods" (output), "EarPods Microphone" (input), "PXP 27-UXO" (external monitor output). If unsure of the exact name, call list_audio_devices first.
- list_audio_devices: List available mics and speakers. No args.
- get_time: Tell the current time and date. No args. The app reads the clock and speaks the answer, so never guess the time yourself.
- media_control: Control music playback. args: {"action": "play" or "pause" or "next" or "previous", "app": "Spotify" or "Music"}. Default app is Spotify.
- open_url: Open a website or a web search in the browser. args: {"url": "full https URL"}. For a search, build the site's search URL with + between words: YouTube https://www.youtube.com/results?search_query=WORDS, Google https://www.google.com/search?q=WORDS, Netflix https://www.netflix.com/search?q=WORDS.
- set_timer: Start a timer. args: {"seconds": number}. Convert minutes and hours to seconds.
- run_shortcut: Run one of Nik's Shortcuts. args: {"name": "the shortcut name exactly as Nik said it"}. Only when Nik names a specific shortcut.
- screenshot: Save a screenshot to the Desktop. No args.
- lock_screen: Turn the display off and lock the Mac. No args.
- dark_mode: Change the system appearance. args: {"mode": "on" or "off" or "toggle"}.
