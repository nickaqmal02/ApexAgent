    If it stops with an error

    You seeWhy, and the fix
    zsh: no such file or directory: yourThe < > were typed. Use alertEmail=you@gmail.com.
    SSM parameter /cdk-bootstrap/hnb659fds/version not foundCDK was never bootstrapped in Singapore. Run the bootstrap command once in CloudShell as the admin.
    not authorized to perform: sts:AssumeRoleThe cdk-deploy inline policy is missing on nick-aerocare. Add it from cloud/iam/nick-aerocare-cdk-deploy.json.
    Unable to resolve AWS accountNo credentials in this terminal. Check aws sts get-caller-identity.
    Stuck on Distribution … CREATE_IN_PROGRESSNormal. CloudFront takes 5 to 10 minutes to reach every edge location. Leave it running.
    ROLLBACK_COMPLETESomething failed and CloudFormation undid everything, so nothing is left billing. Read the first red line above it, fix, run deploy again.
